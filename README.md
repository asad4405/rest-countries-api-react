# 🌍 World Explorer

A responsive and interactive React application built with **TypeScript**, **Tailwind CSS**, and **Vite**. This app fetches country data from the REST API, allowing users to browse countries, track their visited destinations, and collect country flags.

---

## ✨ Features

- 🗺️ **Browse Countries:** Display a list of all countries fetched dynamically via the REST API.
- ✈️ **Visited Tracker:** Mark countries as visited and view them in a dedicated badge/chip section.
- 🚩 **Flag Collector:** Add country flags to a customized selected-flags gallery.
- ⚡ **React Suspense & Hooks:** Utilizes modern React features (`use` hook and `Suspense`) for clean asynchronous data handling.
- 📱 **Fully Responsive:** Styled with Tailwind CSS grid & flexbox layouts, tailored for Mobile, Tablet, and Desktop screens.
- 🛡️ **Type Safety:** Strongly typed components and data models using TypeScript interfaces.

---

## 🛠️ Tech Stack

- **Framework:** [React](https://react.dev/) + [Vite](https://vitejs.dev/)
- **Language:** [TypeScript](https://www.typescriptlang.org/)
- **Styling:** [Tailwind CSS](https://tailwindcss.com/)
- **API Source:** Programming Hero REST Countries API
